# Security reporting

This repository contains public project documentation and screenshots. It does not contain the Nekxsopus application, authentication material, or a hosted service.

For a suspected exposure in this showcase, contact **KSAGlory** privately through the [KSA community](https://discord.gg/ksahub). Use a private message rather than a public channel, and start with a brief description without including secrets. The maintainer can arrange a suitable way to share details.

Do not publish pairing keys, provider credentials, private server configuration, account data, or unredacted runtime logs in an issue. There is no public release support matrix or security response-time guarantee at this development stage.
