# Feedback and support

Nekxsopus is in private development. This repository offers project information, not a public installer or a supported deployment package.

Use GitHub Issues for project questions, documentation corrections, or suggestions for games and challenge categories. Explain the desired task and game edition rather than assuming a catalog entry already has a working connector.

If discussing an owner development test, separate observed behavior from expectations. Remove account identifiers, personal paths, private server addresses, pairing credentials, and unrelated player information from screenshots or logs before posting. Do not upload full workspace exports, server configurations, databases, or model-runtime logs.

Do not report a private security issue in public. See [SECURITY.md](SECURITY.md). Source contributions and installation support are not available through this showcase.

Community: [discord.gg/ksahub](https://discord.gg/ksahub).
